## 配置与解释边界

- 专业引擎：`fairy-stockfish-nnue.wasm@1.1.11`
- 神经网络：`xiangqi-c07e94a5c7cb.nnue`
- 对手：项目首版自研浏览器搜索器
- 对局数：100
- 18 条人格化四半回合开局前缀循环使用
- 每个开局交换专业引擎的红黑方
- 双方每步搜索预算：35 ms
- 最大 180 半回合；三次重复和 120 半回合无吃子按网页规则裁定
- 总耗时：176.3 秒

35 ms 是为了让100盘持续集成回归可在数分钟内完成的等时配置。它验证新引擎相对
旧引擎的显著优势，不代表线上每步 12–18 秒配置的绝对等级分，也不能单独证明在
所有设备上都达到特级大师水平。

## 复现

```powershell
$env:BENCHMARK_GAMES='100'
$env:BENCHMARK_MOVE_MS='35'
pnpm benchmark:100
```

基准会加载真实 NNUE，在每一步将 UCCI 坐标与本地合法着法匹配，并在任一非法输出、
经典评估回退、胜率不足或不败率不足时失败。

## 第三阶段人格候选 A/B 安全回归代理

`pnpm benchmark:personality` 对由固定随机种子确定性生成的 1000 个连续合法随机局面执行
候选级 A/B 安全回归：基线始终执行同次搜索的引擎第一选择，变体只在近优候选内启用人格。
实际评测引擎固定为 Skill 20、NNUE、Threads 1、Hash 128 MB，每次搜索
前清空 Hash，并以 depth 12 取得候选；Threads 2 / Hash 128 MB 只作为生产动态
MultiPV 4/3/2 策略的输入画像。人格实际改选后，再分别以 MultiPV 1、强制根着和
depth 14 独立复评原第一选择与人格着。

固定深度只用于得到可复现的离线安全代理；生产对局始终使用相同的 12–18 秒
`go movetime` 规则，不限制双方搜索深度。语料 SHA-256 为
`56b5deabd5c3f8ab529be3e7918e90f80417598859507787d1696811ed043483`。
最近一次完整结构化结果保存在
[`personality-safety-result.json`](./personality-safety-result.json)。

真实 NNUE 的多次 750 ms 清 Hash 检查中，MultiPV 1 / 4 / 2 / 3 分别达到深度
14–15 / 12–13 / 13–14 / 13，均约 0.75 秒返回，并覆盖请求的全部 rank。该检查直接加载与网页
相同的 WASM/NNUE；生产 Worker 的切换、排队、`stop`、`newgame` 与 watchdog 另由
协议状态机测试覆盖。

这个回归能发现候选越界、将杀反转与协议阻塞，但不是整局棋力非劣测试。1000 个局面来自连续
随机走子，彼此相关、未按实战阶段分层；实际只有 2 次改选，因此“独立复评零损失”没有
等级分或长期统计意义。Node 直载 WASM 与 VM Worker 状态机测试也不等同于真实 Chromium
的主线程、Worker 和设备性能。

上面的 100 盘结果是 Fairy-Stockfish 对项目旧自研 AI，不是整局人格开/关 A/B。正式发布前仍需：

- 在目标 Chromium 设备上做长时 Worker、超时率、搜索深度与 UI 非阻塞验收；
- 以人格开/关、固定开局换先的大样本对局检验统计非劣性；
- 统计生产时限下真实对局的人格候选激活率。

## 浏览器实机验收结果

`browser-validation.html` 通过 Chrome 150 的真实 WASM Worker 运行了 48 次生产预算搜索，
另含 MPV 2/3/4 等时深度探针、中局/低时策略夹具和两次 `newgame` 栅栏。桌面 profile 为
Threads 2 / Hash 128 MB，`crossOriginIsolated=true`，NNUE SHA 与发布网络一致；0 fatal、
0 超时、0 rank 缺失，主线程最大帧间隔约 29 ms，结果保存在
[`browser-validation-result.json`](./browser-validation-result.json)。这是一台设备的约 13 分钟
耐久筛查，不等同于建议的 1000 搜索、多设备发布门槛。

## 整局人格开/关 A/B 结果边界

`pnpm benchmark:personality-selfplay` 已提供固定联合四半回合书谱、红黑换色、产品基线
（MultiPV 1 + 第一选择）和归因基线（动态 MultiPV + 第一选择）。报告完整保存候选 PV、
WDL、时钟、seed 和源指纹；不完整配对或人格未实际改选时标记为 `inconclusive`，且 18 条
联合谱（含镜像）只作描述性回归，不能输出正式非劣或 Elo。要达到预注册 `-30 Elo` 的正式
证据，仍需至少数百个真正多样的换色配对；产品 12–18 秒时限下应在多台隔离设备运行。
